# Organization Constitution

This control plane governs AI-assisted product delivery across managed repositories.

## Core intent

- Use specification-first delivery.
- Prefer small, reviewable increments.
- Keep a human in the loop for ambiguous, risky, security-sensitive, or production-impacting changes.
- Treat project memory, standards, and review outcomes as reusable organizational knowledge.

## Governance rules

1. Every feature should have an explicit problem statement and success signal.
2. Significant work should progress through spec, clarify, plan, tasks, and implementation.
3. Reviews after specify, plan, tasks, and implement are default-on unless explicitly waived.
4. Shared lessons must be promoted to org memory only after human approval.
5. External knowledge sources must come from approved MCP servers or trusted snapshots.
